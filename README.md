# 📦 Sistema de Estoque em Python

Sistema de gerenciamento de estoque desenvolvido em **Python**, com foco na prática de lógica de programação, funções, estruturas de dados, validação de entradas e organização de código em módulos.

## 🎯 Objetivo

O projeto foi desenvolvido como parte da minha evolução nos estudos de programação e tem como objetivo simular um sistema simples de gerenciamento de produtos.

## ⚙️ Funcionalidades

* ✅ Cadastrar produtos
* ✅ Listar produtos cadastrados
* ✅ Buscar produtos
* ✅ Alterar quantidade em estoque
* ✅ Remover produtos
* ✅ Validar nome dos produtos
* ✅ Validar preço e quantidade
* ✅ Tratamento de erros com `try/except`
* ✅ Menu interativo pelo terminal

## 🛠️ Tecnologias utilizadas

* 🐍 Python
* 📚 Estruturas de dados com dicionários
* 🔧 Funções
* 🧩 Módulos e importação entre arquivos
* 🛡️ Tratamento de exceções

## 📁 Estrutura do projeto

```text
sistema-estoque-python/
│
├── README.md
├── main.py
└── estoque.py
```

### `main.py`

Responsável pelo menu principal e pela execução do sistema.

### `estoque.py`

Contém as funções responsáveis pelo gerenciamento dos produtos e do estoque.

## ▶️ Como executar

1. Tenha o **Python** instalado.
2. Clone este repositório.
3. Abra a pasta do projeto no VS Code ou em outro editor.
4. Execute o comando:

```bash
python main.py
```
